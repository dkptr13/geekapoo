## Orden recomendado

1. `post-marca` — presentación.
2. `post-wiki` — qué ofrece la web.
3. `post-catalogo` — cifras.
4. `post-streaming` — utilidad concreta.
5. `post-comunidad` — comunidad.

Las stories pueden ir el mismo día que el post o al día siguiente.

## Notas

- Las portadas son reales del catálogo (One Piece, Jujutsu Kaisen, 86: Eighty Six, Kimetsu no Yaiba, Frieren).
- Las cifras son las del catálogo actual: 200+ series, 9.000+ episodios, 5.600+ personajes.
- En Instagram Stories, el enlace no se puede poner en la imagen: usa el sticker de enlace a `www.geekapoo.es`.
- Los textos de las imágenes son genéricos y verificables; no hay datos inventados.
